# Third-party code and assets

## FreeType and HarfBuzz

Neither is vendored. `build.zig.zon` pins both by the hash of their release
tarballs and `build.zig` describes how they are compiled, so the sources arrive
through the package manager and this repository carries none of them.

What is ours is the build description and `include/ftmodule.h`, the list of
FreeType modules this build registers.

**FreeType** is offered under two mutually exclusive licences and the user
chooses one: the FreeType Licence in `docs/FTL.TXT`, or the GNU General Public
Licence version 2 or any later version. **We take the FreeType Licence.** This
project is BSD-3-Clause and the GNU option would place the combined work under
copyleft.

The FreeType Licence is BSD-style and carries one obligation, its first clause:
a program that uses FreeType has to say so somewhere in its documentation. The
project's own suggested wording is

> Portions of this software are copyright © 2026 The FreeType Project
> (https://freetype.org). All rights reserved.

and it belongs in the documentation of whatever ships this module, not only
here. Its third clause requires nothing: it forbids either party using the
other's name for advertising without written permission.

Nothing here is vendored, so the obligations attach to a binary and not to this
repository. A build carries their code and has to carry their notices with it;
a checkout of these files carries neither.

Inside FreeType, the gzip module is under the zlib licence, and four files in
the auto-hinter are near-verbatim HarfBuzz under the licence below. This build
compiles both.

**HarfBuzz** is under the licence its own `COPYING` calls "Old MIT": use, copy,
modify and distribute are granted without fee, provided the copyright notice
and the two disclaimer paragraphs appear in all copies. So its notice travels
with any distribution that carries the library.

## The Ahem font

`tests/fonts/Ahem.ttf` is the Ahem font from the W3C CSS test suite, taken from
https://www.w3.org/Style/CSS/Test/Fonts/Ahem/. It belongs to the public domain,
with a Creative Commons Zero dedication for jurisdictions that do not recognise
public domain ownership; the statement travels inside the font's own name table
and the full text is at that address under `COPYING`. Nothing is required in
exchange; this entry is provenance rather than attribution.

## The Feature font

`tests/fonts/Feature.ttf` is ours and carries no third-party content. It is
generated by `tools/make_feature_font.py` from the outlines and tables that
script writes, and it exists because Ahem answers nothing about shaping: it has
no `GSUB`, `GPOS` or `kern`. The generator is the authority for every number in
the font, which is what makes the expected values in `tests/feature.zig` exact
by construction rather than measured off a design somebody else made.

It is committed rather than generated at build time so that the test suite needs
no Python. fontTools 4.61.1 produced the file in the tree.
